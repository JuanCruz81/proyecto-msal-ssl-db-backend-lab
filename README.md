Proyecto React + MSAL (Vite)

1. Reemplaza los valores en src/authConfig.js: <YOUR_CLIENT_ID> y <YOUR_TENANT_ID> (o usa "common").
2. Instala dependencias:

   npm install

3. Ejecuta en desarrollo:

   npm run dev

Notas:
- Este scaffold creó archivos pero no instaló dependencias si la red falló; ejecutar npm install localmente.
- Usa el portal de Azure para registrar una app y configurar redirect URI http://localhost:5173
